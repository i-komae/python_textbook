\chapter*{はじめに}
\markboth{はじめに}{はじめに}

本書は、Python を使って自然科学のデータを解析するための入門書である。ファイルから測定値を読み、平均や発生間隔を計算し、結果を図にするところから始める。短い例を実行し、入力した値と表示された答えを見比べながら、処理の意味を学ぶ。

前半では、ファイルの場所を確認する操作、Python の準備、プログラムの書き方、データの読み書きを学ぶ。コードをどこへ保存し、どう実行するかも順に説明する。

中盤では、多数の数値をまとめて計算する NumPy、表を整理する pandas と Polars、図を作る Matplotlib を使う。さらに、SciPy でデータに合う式を求め、Astropy で単位や天体の座標を扱う。それぞれの道具が何を受け取り、どのような結果を返すかを確かめる。

後半では、同じ処理を別のデータにも使うために、関数を別ファイルへまとめる。計算結果を自動で確認する方法や、処理時間を測って改善する方法も学ぶ。最後の総合課題では、複数の観測装置がほぼ同時に記録した事象を探し、ここまでの内容を一つの解析へまとめる。

計算結果が正しいかを確かめることも、学習の一部である。まず手計算できる少数の値で試し、答えが合うことを確認してから、多くのデータへ進む。得られた値だけでなく、使ったデータと計算の手順を説明できるようになることを目指す。

Python の言語仕様と標準ライブラリの説明には、公式チュートリアル~\cite{python_tutorial} と公式ライブラリリファレンス~\cite{python_library} を参照した。これらの資料は、各ライブラリの公式資料とともに巻末の参考文献にまとめた。
