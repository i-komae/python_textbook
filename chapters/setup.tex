\chapter{Python 実行環境の構築}
\label{chap:setup}

\section{最初の計算を実行する}
\label{sec:setup-first}

この章では、Python を準備し、短いコードをファイルへ保存して実行する。計算結果の \code{5} を表示し、コードの変更後に \code{12} へ変わることを確認するのが最初の目標である。準備にはインターネット接続を使う。

\subsection{OS に合う端末を開く}

macOS では「ターミナル」を開く。Windows では前章の手順で WSL 上の Ubuntu を用意し、Ubuntu の端末を開く。以下の命令はその端末に入力する。Windows の PowerShell へそのまま入力する命令ではない。

以下では、どちらの OS でも uv を使って Python 3.12 と作業用の環境を用意する。Python の導入と仮想環境の詳細は、最初の計算を試した後に説明する。

\subsection{uv を用意する}

\code{uv --version} で番号が表示される場合は、次の小節へ進む。\code{command not found} と表示される場合は、公式の導入スクリプト~\cite{uv_install} を保存する。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
$ curl -fLsS https://astral.sh/uv/install.sh -o uv-install.sh
$ less uv-install.sh
\end{lstlisting}

\code{less} の表示は \code{q} で閉じる。取得元とスクリプトの内容を確認したうえで、次を実行する。導入先や変更内容はスクリプトが表示する案内で確認する。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
$ sh uv-install.sh
\end{lstlisting}

導入後は、新しい端末を開いて \code{uv --version} を実行する。\code{uv 0.x.y} のように番号が出れば、次へ進める。番号自体は導入時期によって変わる。

\subsection{作業用フォルダーと Python を用意する}

次の命令を 1 行ずつ実行する。\code{analysis\_practice} には、この章で作るファイルを保存する。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
$ cd ~
$ mkdir -p analysis_practice
$ cd analysis_practice
$ uv venv --python 3.12 --seed .venv
$ source .venv/bin/activate
$ python --version
\end{lstlisting}

\code{uv venv} は、使用する Python と追加ライブラリをまとめる作業用の環境を \code{.venv} に作る。指定した Python が手元になければ、uv が取得する。\code{--seed} は後で使う pip もこの環境へ入れる指定である。\code{source} の行は、この端末でその環境を使い始める命令である。

最後に \code{Python 3.12.x} と表示されることを確認する。\code{x} の部分は更新によって変わる。このように作業ごとに用意する環境を「仮想環境」\index{かそうかんきょう@仮想環境|textbf}という。

\subsection{Python ファイルを保存して実行する}

コードを書くには、文字だけのファイルを編集するテキストエディタを使う。ここでは、端末内で使えるエディタ \code{nano} を例にする。\code{analysis\_practice} にいることを \code{pwd} で確認し、次を入力する。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
$ nano first_calculation.py
\end{lstlisting}

編集画面が開いたら、次の 2 行を入力する。左側の行番号は入力しない。

\begin{lstlisting}[language=Python, title={first\_calculation.py}]
count = 3
print(count + 2)
\end{lstlisting}

Ctrl キーを押しながら O を押すと、保存するファイル名の確認が出る。Enter で確定し、Ctrl+X でエディタを閉じる。\code{nano} を使えない場合や使い慣れたエディタがある場合は、そのエディタで同じ内容を保存してよい。ファイル形式は標準テキスト、文字コードは UTF-8 とし、名前の末尾が \code{.py.txt} にならないようにする。

ターミナルへ戻ったら、保存したファイルを実行する。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
$ python first_calculation.py
5
\end{lstlisting}

\code{python} は Python を起動する命令であり、後ろの \code{first\_calculation.py} は実行するファイル名である。\code{print()} は括弧内の計算結果を画面に表示する。\code{5} が表示されれば、保存したコードを実行できている。

もう一度 \code{nano first\_calculation.py} で開き、\code{count = 3} を \code{count = 10} へ変えて保存する。同じ実行コマンドで \code{12} が表示されることを確認する。このように、編集、保存、実行、結果の確認を繰り返してプログラムを作る。

\code{can't open file} と表示されたら、\code{pwd} と \code{ls} で現在位置とファイル名を確かめる。\code{SyntaxError} と表示されたら、表示された行の括弧や引用符などを見本と比べる。エラーの詳しい読み方は第~\ref{chap:basics}~章で説明する。

\subsection{作業を終える・再開する}

作業を終えたら、端末で \code{deactivate} を実行して仮想環境の利用を終える。作成したファイルや環境は削除されない。再開するときは、新しく開いた端末で次を実行する。環境を毎回作り直す必要はない。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
$ cd ~/analysis_practice
$ source .venv/bin/activate
$ python first_calculation.py
12
\end{lstlisting}

\section{使っている Python を確認する}

ここからは、最初の手順で何を用意したかを確かめる。Python 本体はコードを実行する。仮想環境を使うと、作業ごとに追加ライブラリを分けて管理できる。

以下は、\code{analysis\_practice} フォルダーへ移動し、\code{source .venv/bin/activate} で仮想環境を有効にした端末で実行する。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
$ python --version
$ command -v python
$ python -c "import sys; print(sys.executable)"
\end{lstlisting}

1 行目は版、2 行目はシェルが見つけた命令の場所、3 行目は実際に起動した Python の実行ファイルの場所を表示する。\code{-c} は、後ろの引用符内を Python コードとして実行する指定である。ここでは \code{sys} という Python 付属の機能で、実行ファイルの場所を表示している。仮想環境を使っていれば、2 行目と 3 行目には通常 \code{analysis\_practice/.venv/bin/python} を含むパスが出る。値が異なる場合は、現在のフォルダーと仮想環境の有効化を確認する。

\section{解析用ライブラリを追加する}
\label{sec:setup-libraries}

ライブラリは、計算や作図などの機能をまとめたものである。Python に最初から含まれる標準ライブラリと、自分で追加する外部ライブラリがある。例えば平方根を求める \code{math} は標準ライブラリであり、図を作る Matplotlib は外部ライブラリである。本書で使う主な外部ライブラリを表~\ref{tab:packages} に示す。それぞれの具体的な使い方は、対応する章で学ぶ。

\begin{table}[hbtp]
\centering
\caption{本書で使う主なライブラリと役割}
\label{tab:packages}
\begin{tabular}{ll}
\toprule
ライブラリ & 主な役割 \\
\midrule
NumPy & 多数の数値の計算 \\
pandas、Polars & 表の読み込み、加工、集計 \\
Matplotlib & 図の作成と保存 \\
SciPy & データへの式の当てはめなどの数値計算 \\
Astropy & 単位、時刻、天体の座標の扱い \\
tqdm & 処理の進み具合の表示 \\
\bottomrule
\end{tabular}
\end{table}

\code{analysis\_practice} の仮想環境を有効にした端末で、次を実行する。\code{pip} は外部ライブラリを導入する道具である。\code{python -m pip} と書くことで、現在使っている Python に対応する pip を実行できる。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
$ python -m pip install numpy pandas polars matplotlib scipy astropy tqdm
\end{lstlisting}

途中には取得状況やライブラリ名が表示される。最後にエラーが出ずに入力待ちへ戻ったら、次の命令で、導入した機能を Python から読み込めるか確認する。\code{import} はライブラリを使うための読み込み命令である。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
$ python -c "import numpy, pandas, polars, matplotlib, scipy, astropy, tqdm; print('OK')"
OK
\end{lstlisting}

\code{ModuleNotFoundError} が出た場合は、表示された名前のライブラリを読み込めていない。仮想環境を有効にしたか、導入時の名前を間違えていないかを確認する。

\section{章末課題：保存したプログラムを実行する}

第~\ref{sec:setup-first}~節で作った \code{\textasciitilde/analysis\_practice} で行う。端末で \code{cd \textasciitilde/analysis\_practice}、\code{source .venv/bin/activate} の順に実行してから始める。

\begin{enumerate}

\item \begin{minipage}[t]{\linewidth}
\textbf{Python とライブラリを確認し、作業を再開する。}

\end{minipage}

\end{enumerate}
