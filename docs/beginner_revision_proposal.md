各節は、次の順で書く。

2. **入力する場所を示す。** ターミナル、Notebookのコードセル、保存するPythonファイルを区別する。
3. **小さなデータで実行する。** 初めて使う操作は、何を処理しているかを目で追える量にする。
4. **表示結果をすぐ下に置く。** 出力のどの部分を見るかも説明する。
5. **コードと結果を対応させる。** 変数名だけでなく、実際の値を使って説明する。
6. **条件を一つ変えて確かめる。** その後で、正式な用語や詳しい仕組みへ進む。

### 配列の差分を途中の値まで示す

対象は `chapters/numpy.tex` の10〜27行である。

現在の `times[1:] - times[:-1]` は、配列の作成、スライス、配列同士の引き算を一度に使う。先に、差分が何を表すかを説明する。

> ある観測の開始から10秒、15秒、23秒、41秒の時点で、4回の事象が記録されたとする。知りたいのは、次の事象が起きるまでに何秒かかったかである。
>
> 最初の間隔は`15 - 10`で5秒、次は`23 - 15`で8秒、最後は`41 - 23`で18秒になる。

> この計算には、複数の数値をまとめて扱う「配列」を使う。`import numpy as np`は、NumPyの機能を`np`という短い名前で使うための準備である。`np.array([10, 15, 23, 41])`で4個の数値をまとめた配列を作る。

```python
import numpy as np

times = np.array([10, 15, 23, 41])
intervals = np.diff(times)
print(intervals)
```

表示結果は次のようになる。

```text
[ 5  8 18]
```

> `np.diff(times)`は、後ろの値から一つ前の値を引く計算を順に行う。時刻が4個あるので、隣り合う時刻の間隔は3個になる。

スライスを学ぶ節で、次の計算が同じ結果になることを示す。

```python
import numpy as np

times = np.array([10, 15, 23, 41])
later = times[1:]
earlier = times[:-1]
print(later)
print(earlier)
print(later - earlier)
```

```text
[15 23 41]
[10 15 23]
[ 5  8 18]
```

> `times[1:]`は先頭を除いた3個、`times[:-1]`は末尾を除いた3個を取り出す。配列同士の引き算では、同じ位置にある値同士を引く。したがって、`15 - 10`、`23 - 15`、`41 - 23`をまとめて計算できる。

### axisを足し算の対応で説明する

対象は `chapters/numpy.tex` の211〜242行である。

「0軸に沿って集計するため各列の和を返す」という説明に、どの値を足すかを加える。

> 次の2行3列の配列で、列ごとの合計と行ごとの合計を求める。`sum()`は合計を求める操作であり、丸括弧の中の`axis`で、どの方向に並ぶ値を足すかを指定する。

```python
import numpy as np

values = np.array([[1, 2, 3],
                   [4, 5, 6]])
print(values.sum(axis=0))
print(values.sum(axis=1))
```

```text
[5 7 9]
[ 6 15]
```

> `axis=0`では、各列を上から下へ足す。1列目は`1 + 4`、2列目は`2 + 5`、3列目は`3 + 6`なので、結果は`[5, 7, 9]`になる。
>
> `axis=1`では、各行を左から右へ足す。1行目は`1 + 2 + 3`、2行目は`4 + 5 + 6`なので、結果は`[6, 15]`になる。
>
> ここでの説明は2次元の配列についてのものである。3次元以上の配列では、配列の形と、集計する軸を対応させて考える。

### フィットで求めたい値を先に示す

対象は `chapters/scipy.tex` の23〜29行である。

繰り返されている定義をまとめ、最初は直線に対象を絞る。

> 横軸を`x`、縦軸を`y`としてデータを描くと、点がおおむね直線に沿って並ぶ場合がある。そこで、直線を表す式`y = a * x + b`を使い、点の並びに合う`a`と`b`を求める。
>
> `a`は直線の傾き、`b`は`x = 0`のときの`y`の値である。このように、データに合わせて式の中の値を求めることを「フィット」という。ここでは、各点の`y`と直線の`y`の差を二乗し、その合計が小さくなるように`a`と`b`を求める。
>
> 求めた直線はデータと同じ図に描く。その後で、各点と直線の間にどのようなずれが残っているかを確かめる。

続く例で「式の中で調整する値」をパラメータ、「観測値から式による値を引いた差」を残差と呼ぶことを説明する。誤差の重み付けや共分散は、その後の小節で扱う。実データに直線を使う根拠や、推定値の不確かさに関する説明は残す。

### 総合課題の二つの時刻差を具体例で区別する

対象は `chapters/assignment.tex` の90〜104行である。

同時観測を判定するための差と、見つかった対同士の間隔を、別々の小節で説明する。

> まず、2つの検出器が記録した時刻を比べる。検出器Aが1000 ns、検出器Bが1180 nsに記録していれば、時刻差の絶対値は180 nsである。異なる検出器の記録であり、差が250 ns以内なので、この2件を同時観測の1組として数える。250 nsちょうどの差も含める。
>
> 次に、同時観測として見つかった各組へ、その組を代表する時刻を付ける。ここでは2件の時刻の平均を使う。1000 nsと1180 nsの組の代表時刻は1090 nsになる。
>
> 別の組の代表時刻が2000 nsなら、2組の間隔は`2000 - 1090`で910 nsになる。180 nsは一つの組を作る2件の間の差であり、910 nsは二つの組の代表時刻の間の差である。別々の図に描き、軸ラベルで何の差かを示す。

この例の後に、符号の決め方、同じ事象を共有する複数の対、日付境界、平均時刻を正確に保持する方法を順に説明する。整数ナノ秒の利用と平均の2倍を保存する方法は、実データのコードを示す前に扱う。フィットへ進む前には、250 nsの選択範囲とモデルの規格化を説明する。
