\chapter*{はじめに}
\markboth{はじめに}{はじめに}

自然科学のデータ解析では、Python の文法を知っているだけでは十分ではない。ファイルと実行環境を確認し、データを適切な型で読み込み、計算結果を検証して図にまとめる必要がある。データ量が増えた場合には、結果を変えずに処理時間とメモリ使用量を改善する。本書は、この一連の作業を自力で組み立てられるようになることを目的とする。

本書の前半では、シェルによるファイル操作、Python の導入と仮想環境、Python の基本構文、データの入出力を扱う。シェルと環境管理は導入時だけの準備ではなく、入力の確認、スクリプトの実行、ログの保存、別の計算機への転送を含む解析基盤である。

中盤では、NumPy、pandas、Polars、Matplotlib、SciPy、Astropy を扱う。NumPy で数値配列を計算し、pandas と Polars で表形式データを整形・集計し、Matplotlib で結果を可視化する。SciPy は統計、フィット、補間、信号処理などの数値計算を担い、Astropy は物理単位、時刻系、天球座標、FITS 形式を扱う。それぞれのライブラリを孤立した道具として覚えるのではなく、同じ解析の中で役割を分担させる方法を説明する。

後半では、繰り返し使う処理を自作モジュールやパッケージとして整理し、テストと依存関係を含めて再利用する方法を学ぶ。その後、計算量、ベクトル化、メモリ使用量、逐次処理、プロファイリングを基に性能を改善する。巻末の総合課題では、これらの内容を用いて、複数の観測装置が \(250\,\mathrm{ns}\) 以内に記録したイベントを同時観測とみなして探索する。

コードが例外を出さずに終了したことは、解析結果が正しいことを意味しない。本書では、既知の答えを持つ小さな入力を作る、配列の形状や型を表示する、図と残差を調べる、高速化の前後で同じ結果が得られることを確認する、といった検証を重視する。自然科学の解析では、どの値を得たかだけでなく、どの条件と手順で得たかを説明できることが重要である。

Python の言語仕様と標準ライブラリには、公式チュートリアル~\cite{python_tutorial} と公式ライブラリリファレンス~\cite{python_library} を用い、各ライブラリの公式資料とともに巻末へまとめた。

シェルの実行例は macOS、Linux、Windows Subsystem for Linux (WSL) で共通する書き方を基本とし、プロンプトを \code{\$} で示す。実装によってオプションが異なる場合は、手元の環境で \code{--help} または \code{man} を確認する。
