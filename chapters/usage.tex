\chapter{本書の構成と実行例の読み方}
\label{chap:usage}

\section{対象と到達目標}

本書では、Python を使ってデータを読み、計算し、図を作るところから学ぶ。Python やターミナル操作が初めての読者は、前から順に読み、短い例を一つずつ実行する。既に解析コードを書いている読者は、必要な章から読み始めてもよい。

学習を進めると、次の作業ができるようになる。
\begin{itemize}
\item データが保存されている場所を確認し、プログラムを実行する。
\item ファイルから数値や表を読み、平均や発生間隔を求める。
\item 計算結果を図にし、ラベルや単位を付けて保存する。
\item 小さな入力で答えを確かめ、同じ計算を別のデータにも使う。
\item 正しい結果を保ちながら、処理時間とメモリ使用量を減らす。
\end{itemize}

後半の例は、それ以前の章で導入した用語とファイルを使う。分からない用語は索引から説明箇所を探せる。索引の太字のページ番号は主な説明箇所を、矢印は別の見出しへの参照を示す。

\section{ファイルを開くところから解析までの順序}

章は、実際の作業を次の順で進められるように並んでいる。

\begin{enumerate}
\item \textbf{ファイルの場所を確かめて Python を起動する}。シェルの章でフォルダーの移動とファイルの表示を試す。次の環境構築の章で Python を用意し、短いプログラムをファイルへ保存して実行する。
\item \textbf{短いプログラムを書いてデータを読む}。基本構文の章で値、条件分岐、反復、関数を学ぶ。入出力の章では、ファイルの文字列を数値や表として読み込む。
\item \textbf{数値や表を使って計算し、図にする}。NumPy で配列を計算し、pandas と Polars で表を整理する。Matplotlib で図を作り、SciPy でモデルを当てはめる。Astropy では単位、時刻、天体の座標を扱う。
\item \textbf{同じ処理を繰り返し使い、処理時間を減らす}。関数を別のファイルへ分け、結果を自動で確認する方法を学ぶ。処理時間を測り、正しい答えを保ちながら計算方法を改善する。最後の総合課題では、これらを一つの解析へまとめる。
\end{enumerate}

最初は、第~\ref{chap:shell}~章から第~\ref{chap:io}~章までを順に進め、ファイルを読み書きする短いプログラムを実行できるようにする。その後は、扱うデータと目的に応じて各ライブラリの章へ進む。例えば、数値の列を計算して図にしたい場合は NumPy と Matplotlib、表を集計したい場合は pandas が出発点になる。Polars は別の表処理方法として、Astropy は単位や天体データを扱うときに参照できる。「補足」と「発展課題」は、基本の例を理解してから取り組む。

例えば、CSV に保存された数値の平均を求めたいときは、まずファイルの場所と内容を確認し、それから読み込んで計算する。結果だけを見て判断せず、入力が何件あり、どの値を計算に使ったかも確かめる。

\section{コード例と実行結果の読み方}

コード例の最初に、入力する場所を確認する。ターミナルに入力する命令と、Python に入力するコードは別である。ターミナルの例では行頭に \code{\$} を付けるが、この印自体は入力しない。Python の例は、原則として拡張子が \code{.py} のテキストファイルへ保存して実行する。このファイルを Python スクリプトという。保存と実行の手順は第~\ref{chap:setup}~章で説明する。

ここでは、コードと表示結果の区別を見ておく。次は、計算する内容を記したコードである。

\begin{lstlisting}[language=Python]
count = 3
print(count + 2)
\end{lstlisting}

表示結果は次のようになる。

\begin{lstlisting}[numbers=none, xleftmargin=2\zw]
5
\end{lstlisting}

1 行目では、\code{3} という値に \code{count} という名前を付ける。2 行目では、その値に \code{2} を足し、\code{print()} で結果を画面に表示する。丸括弧の中に、表示したい値や計算式を書く。この例では \code{5} が表示されれば、同じ計算を実行できている。

\code{count = 3} を \code{count = 10} へ変えると、計算結果は \code{12} になる。ファイルを書き換えた場合は、保存してからもう一度実行し、表示が変わることを確認する。

第~\ref{chap:basics}~章には、Python を起動して 1 行ずつ試す「対話モード」の例もある。この場合は入力行に \code{>>>}、続きの行に \code{...} を示す。どちらの印も入力しない。コードの左に付いた行番号も入力しない。

同じ変数を使う続きの例は、その変数を作ったコードの下へ追記して実行する。各章の冒頭に、作業フォルダーへ移動する命令を示す。その場所で Python ファイルを実行すると、ファイル名だけで指定した入力や出力も、その場所を基準に扱われる。表示結果や \code{\$}、\code{>>>} の印はファイルに書かない。エラーを起こす例は、その動作を確認するために実行し、後の処理を試す前に取り除く。ファイルを読む例では、先に示すデータを指定した名前で保存する。図を作る例では、保存したファイルを開き、軸や値を確かめる。

パス、バージョン番号、処理時間は環境によって異なる。例えば \code{Python 3.12.14} と表示される箇所は、手元では別の番号になる場合がある。これらは番号や文字列全体の一致を求めず、各例で示した確認事項に沿って読む。

\section{章末課題の進め方}

章末課題では、その章の内容を、それ以前に学んだ操作と組み合わせて使う。各課題の冒頭で作業場所と保存する Python ファイル名を示す。前章のファイルを引き継ぐ場合は、どのファイルを使うかも確認する。地震カタログの元の CSV は、第~\ref{chap:shell}~章で作る \code{\textasciitilde/earthquake\_practice/raw} に保存する。別の作業フォルダーから使う場合は、読み込むコードにその保存先を指定する。本文中の少数行の CSV は動作確認用の人工データであり、USGS の実際の観測値とは区別する。小さな検証用データで処理を確かめた後、配布データまたは読者自身のデータへ適用する流れが基本となる。

課題に示す数値の目安は、コードの誤りに気付くために使う。自分の答えと違うときは、使った入力と計算の手順を本文の例と比べる。図を提出する問題では、保存した図を開き、軸の名前と単位が付いていることや、どのデータを描いたかが分かることも確認する。

第~\ref{chap:kadai}~章の総合課題は、複数の章で学んだ処理を組み合わせる課題である。課題用スクリプトとデータの入手先は同章に記載した。作業順序は、配布コードによる入出力の把握、小規模データによる正しさの検証、大規模データの処理、性能改善である。

課題で「結果を示せ」とある場合は、端末に表示された値や保存した図を、レポートまたは発表資料へ載せる。使った入力、行った処理、結果の表や図、そこから分かったことの順にまとめる。発表ではコードの全行を読み上げるのではなく、選んだ方法と結果の意味を説明する。

\section{入力・実行条件・結果の検証記録}

エラーが出ずにプログラムが終わっても、意図した計算ができているとは限らない。各章では、次の点を確認する。

\begin{itemize}
\item 少数の値を使い、手計算の答えと表示結果を比べる。
\item ファイルを読むときは、先頭の数行と件数を確認する。
\item 図や計算方法を変えたときは、同じ入力で結果を比べる。
\end{itemize}

使った入力ファイル、実行した命令、表示結果や保存先をメモしておくと、後から同じ作業を繰り返せる。型、単位、計算条件など、その章で必要になる確認事項は、各例の説明で扱う。

\section{公式資料・付録・参考文献の参照方法}
\label{sec:reference-guide}

本文で取り上げるコマンドやライブラリの使い方は、ソフトウェアの更新によって変わる。本文では概念と代表的な使用例を説明する。指定できる項目の全一覧、関数が返す値、バージョンごとの違いを調べる場合は、公式資料を参照せよ。引用資料は巻末の参考文献にまとめた。

Python の言語仕様と標準ライブラリについては、Python 公式チュートリアル~\cite{python_tutorial} と公式ライブラリリファレンス~\cite{python_library} を参照した。環境構築には uv の公式資料~\cite{uv_docs}、主要な解析ライブラリには各プロジェクトの公式資料~\cite{numpy_quickstart,pandas_tutorials,polars_concepts,matplotlib_quick_start,scipy_user_guide,astropy_user_guide} を用いた。

OS は、macOS、Windows、Linux など、コンピュータの基本的な動作を管理するソフトウェアである。同じ名前のシェルコマンドでも、OS やソフトウェアのバージョンによって書き方が異なる場合がある。手元のコンピュータに入っているコマンドの使い方を表示する方法は、第~\ref{chap:shell}~章で具体例とともに説明する。付録は、環境の切り替え、別の計算機への接続、変更履歴の管理などが必要になったときに参照する。本文の基本例を進める前に、付録をすべて読む必要はない。

次章では、まずターミナルを開き、ファイルがどこにあるかを確認する。
